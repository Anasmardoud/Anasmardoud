## Featured Projects

### ⚖️ [LawDirect.ai](https://github.com/amirboughanem/LawDirect.ai)

**AI-powered lawyer recommendation platform for Lebanon**

Built a semantic matching pipeline that turns a natural-language legal situation into a ranked list of relevant lawyers.

`Vue.js` `Node.js` `Express` `Supabase` `PostgreSQL` `pgvector` `Hugging Face` `Fly.io`

- Semantic vector search using BAAI embeddings
- Privacy-first processing with no case-description storage
- REST API for search, profiles, and image delivery
- Modular full-stack architecture
- Team-based development and deployment

### 🌾 [Mazrouii](https://github.com/Anasmardoud/Mazrouii)

**Arabic-first AI system for agricultural and household expense management**

`Vue.js` `Node.js` `Supabase` `AI Vision` `Speech-to-Text`

- Bilingual Arabic-first experience
- AI-assisted receipt and expense extraction
- Voice-to-expense workflow
- Human approval before database writes
- Designed around real agricultural and family-business needs

### 🏨 [NovaStay](https://github.com/Anasmardoud/NovaStay)

**Hotel reservation and operations desktop application**

`C#` `.NET` `WPF` `Entity Framework Core` `SQL Server` `Telerik UI`

- Customer, room, and reservation modules
- Reservation conflict detection
- Input validation and layered architecture
- Modern WPF interface for reception workflows

### 🏦 Nova Bank

**Secure online banking system**

`PHP` `MySQL` `HTML` `CSS`

- Account and transaction workflows
- Repository and Factory patterns
- Session-based authentication
- SQL-injection and XSS prevention
- Normalized and indexed relational schema
